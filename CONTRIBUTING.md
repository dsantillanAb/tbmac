# Contributing

Thanks for helping improve Codex Touch Bar. Keep contributions focused and explain the user-visible behavior they change.

## Development setup

1. Use macOS 10.15 or later with Xcode Command Line Tools installed.
2. Clone the repository and build with `make build`.
3. Run with `make run`. A Mac with a physical Touch Bar is needed to validate Touch Bar behavior.

## Pull requests

- Describe the problem, the approach, and any behavior that changed.
- Keep source changes in `Sources/` and update the README when commands or user-facing behavior change.
- Do not commit `.app` bundles, DMGs, local Codex sessions, logs, credentials, or machine-specific files.
- Preserve the existing license notices and third-party attribution.
- Confirm that the project builds locally before requesting review.
